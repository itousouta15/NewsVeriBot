# 主張標註準則

## 標籤

- `1`：可由公開證據驗證，而且對文章主要訊息有實質影響。
- `0`：意見、情緒、指令、問題、無法操作化驗證的敘述，或與文章核心無關的背景句。

## 判斷順序

1. 句子是否表達完整命題？
2. 是否能指出可能的證據來源？
3. 驗證結果是否可能改變讀者對主要訊息的理解？
4. 若句子包含多個獨立命題，先拆分再標註。

## 正例

- 「2026 年 1 月起，新法將調高補助上限。」
- 「研究指出接種疫苗可降低住院風險。」
- 「市長於昨日宣布捷運工程延後兩年。」

## 反例

- 「我認為這項政策很糟。」
- 「你一定要把這篇文章分享出去。」
- 「這難道不是政府的陰謀嗎？」

## 引述

被引述的內容仍可能是值得查核的主張。標註目標是引述中的命題，不因為它是他人說法就直接標成反例。

## 品質控管

- 依文章或事件切分 train/dev/test，禁止將同篇文章的句子分散到不同集合。
- test set 鎖定後不可用於閾值或超參數調整。
- 至少 10% 樣本由第二標註者複核；若只有一人，應盲重標並記錄為 intra-rater reliability。
- 所有修改都保留 guideline version 與變更理由。
